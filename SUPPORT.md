# Support

Thanks for using a KMJ TECHNO open-source project.

## Getting help

1. Read the repository README and documentation first.
2. Search existing issues before opening a new one.
3. For reproducible bugs, open a GitHub issue with the affected version/commit, operating system, steps to reproduce, expected behavior, actual behavior, and relevant redacted logs.
4. For feature proposals, describe the user problem, intended outcome, and any compatibility or security considerations.

## Security vulnerabilities

Do **not** disclose suspected vulnerabilities in public issues. Follow this repository's SECURITY.md and use its private reporting path.

## Commercial and account support

For KMJ TECHNO products, licensing, or commercial services, visit https://kmjtechno.com.

Please never include passwords, API keys, access tokens, private keys, personal data, or other secrets in public reports.
