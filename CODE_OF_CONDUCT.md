# Code of Conduct

KMJ Desktop Commander contributors are expected to keep collaboration professional, respectful, and focused on the work.

Harassment, threats, discrimination, deliberate disruption, publication of private information, or abusive behavior are not acceptable.

Project maintainers may edit, hide, reject, or remove contributions and participation that violate these expectations. Security reports should follow SECURITY.md and should not expose exploitable details publicly.

This project welcomes technical disagreement. Critique ideas and implementations, not people.
